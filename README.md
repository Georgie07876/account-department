# Сайт кафедры бухгалтерского учета и контроллинга

Сайт кафедры РГЭУ (РИНХ). Стек: Nuxt 4, Vue 3, TypeScript. Страницы и материалы подготовлены по макету кафедры.

## Локальный запуск

Нужен Node.js 24.15+ и npm. CI также использует Node.js 24.

```bash
git clone https://github.com/Georgie07876/account-department.git
cd account-department
git switch dev
npm ci
npm run dev
```

Nuxt выведет адрес в терминал. По умолчанию сайт открывается на `http://localhost:3000`. Для остановки сервера нажмите `Ctrl+C`.

## Проверки

```bash
npm run lint
npm run format:check
npm run generate
```

Для проверки серверной сборки локально:

```bash
npm run build
npm run preview
```

В `.gitlab-ci.yml` настроены проверки ветки `dev`. Развёртывание на сервер в этом файле не настроено.

Рабочая ветка проекта — `dev`. Изменения в `master` не вносите.

## Структура проекта

| Путь                            | Содержимое                       |
| ------------------------------- | -------------------------------- |
| `app/pages/`                    | Страницы сайта и маршруты Nuxt   |
| `app/pages/programs/[slug].vue` | Страница программы по её `slug`  |
| `app/data/programs.ts`          | Список образовательных программ  |
| `app/data/site.ts`              | Контакты и пункты основного меню |
| `app/components/`               | Шапка и подвал сайта             |
| `app/assets/css/main.css`       | Стили и классы страниц           |
| `public/assets/`                | Изображения                      |
| `public/materials/`             | Локальные документы              |

Страницы программ используют общий шаблон. Чтобы изменить название, описание или ссылку на презентацию программы, правьте `app/data/programs.ts`. Остальной текст находится в соответствующих файлах `app/pages/`.

Краткие описания программ не заменяют утверждённые учебные планы. Список сведений, которые нужно подтвердить перед публикацией, находится на странице `/sources`. Размещение проекта на официальном сайте университета согласовывается отдельно.
